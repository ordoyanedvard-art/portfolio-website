# Портфолио — AI Visual Producer

Статический сайт-портфолио на Next.js 15. Тёмная брутальная сетка, один красный акцент, 16 работ с просмотрщиком и отдельными адресами кейсов.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка, 21 статическая страница
```

## Что где лежит

```
src/data/site.ts      контакты, цифры, услуги, инструменты, hero-видео
src/data/works.ts     16 работ: 8 видео + 8 фотосессий
src/lib/types.ts      типы контента
src/components/       секции 01–08
src/app/work/[slug]/  страницы кейсов, генерируются из works.ts
public/placeholders/  SVG-заглушки, удалить после наполнения
```

## Шаг 1. Свои данные

Открыть `src/data/site.ts` и заменить:

- `name`, `role`, `location`
- `email`, `telegram`, `behance`, `instagram`
- `url` — адрес после деплоя на Vercel, нужен для превью ссылок
- цифры в `stats`, если поменялись

## Шаг 2. Импорт работ одной командой (рекомендуется)

Вместо ручной правки `works.ts` разложи материалы по папкам и запусти импорт — файл соберётся сам, включая размеры изображений и пропорции плиток.

Структура:

```
public/works/
  01-video-neon-district/
    cover.jpg
    info.txt
  02-photo-silk-lookbook/
    cover.jpg
    01.jpg  02.jpg  03.jpg  04.jpg
    info.txt
```

Правила именования папок:

- номер в начале задаёт порядок в сетке
- `video` или `photo` в имени задаёт тип работы
- остаток имени становится адресом кейса: `/work/neon-district`

Файл `info.txt` внутри каждой папки:

```
title: Neon District
client: Бренд одежды
role: Промо-ролик, полный цикл
year: 2026
tags: Midjourney, Runway Gen-3, Kling AI
mux: aBcD1234efGh5678
url: https://behance.net/a30ea301
featured: true
```

Все поля необязательные. `mux` — только для видео, `url` — ссылка на полную версию, `featured: true` растягивает плитку на две колонки.

Обложкой становится файл с именем `cover`, остальные изображения идут кадрами в просмотрщик. Пропорция плитки определяется по размерам обложки автоматически, но её можно задать вручную строкой `aspect: 9/16`.

Запуск:

```bash
npm run import
```

Скрипт перезапишет `src/data/works.ts` и предупредит, если у видео не указан `mux` или у файла не удалось прочитать размеры.

## Шаг 2б. Ручное заполнение

Если хочется править вручную — путь в `works.ts` указывается так:

```ts
cover: {
  src: "/works/01-neon-district/cover.jpg",
  alt: "Neon District — обложка работы",
  width: 1080,
  height: 1920,
}
```

`width` и `height` обязательны — по ним резервируется место, страница не прыгает при загрузке.

Когда изображений станет много (40+), стоит перенести их на Cloudinary: тогда браузер получит AVIF/WebP нужного размера вместо исходных JPEG. Пути в `works.ts` меняются на Cloudinary URL, остальное не трогается.

## Шаг 3. Видео

Держать mp4 в репозитории нельзя — сборка распухнет, страница будет грузиться минуту. Порядок:

1. Загрузить ролик в Mux (mux.com, бесплатный старт)
2. Скопировать Playback ID
3. Вписать в работу:

```ts
muxPlaybackId: "aBcD1234efGh5678",
```

Обложка при этом не нужна — Mux сам отдаст кадр. Ховер-превью в сетке и постер собираются из того же Playback ID автоматически.

Фоновое видео первого экрана — тот же способ, поле `heroMuxPlaybackId` в `site.ts`. Пока оно пустое, вместо видео показывается тёмный градиент с сеткой.

## Шаг 4. Добавить или убрать работу

Всё в `works.ts`. Массив `works` задаёт и порядок в сетке, и адреса кейсов, и нумерацию.

- `aspect` — пропорция плитки: `"9/16"` вертикаль, `"16/9"` горизонталь, `"4/5"`, `"1/1"`
- `featured: true` — плитка занимает две колонки на широком экране. Не ставить больше четырёх, иначе сетка расползётся
- `slug` — часть адреса. Менять после публикации не стоит, ссылки перестанут работать

## Шаг 5. Деплой

```bash
git init && git add . && git commit -m "init"
```

Дальше запушить в GitHub, на vercel.com подключить репозиторий. Сборка подхватится сама, настраивать ничего не надо. После первого деплоя вписать полученный адрес в `site.url` и запушить снова — иначе превью ссылок в Telegram будут ломаться.

## Доступность

- вся сетка работает с клавиатуры, плитки — кнопки
- просмотрщик запирает фокус, закрывается на Esc, листается стрелками
- `prefers-reduced-motion` выключает инерционный скролл, появления и бегущую строку
- ссылка «Перейти к работам» первым фокусом для скринридеров

Полная проверка на соответствие WCAG требует ручного тестирования со скринридером и оценки специалистом — здесь сделана техническая база.

## SEO

Карта сайта и robots.txt генерируются автоматически из `works.ts` — при добавлении работы обновлять ничего не нужно. Оба файла берут адрес из `site.url`, так что после деплоя его важно вписать.

У каждого кейса свои OG-теги: в мессенджере ссылка `/work/night-drive` покажет название, клиента и обложку именно этой работы. Для видео превью берётся кадром из Mux, для фотосессий — обложкой серии.

## Стек

Next.js 15 · TypeScript · Tailwind CSS 4 · Motion · Lenis · Mux Player

Шрифты: Unbounded (заголовки) и Inter Tight (текст), оба с кириллицей, самохостятся при сборке.
