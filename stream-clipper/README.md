# Stream Clipper — автонарезка лучших моментов стримов GTA 6

Программа сама находит **самых смотримых русских стримеров**, которые сейчас играют в GTA 6.
Она пишет их эфиры, следит за чатом и, когда чат «взрывается», вырезает этот момент.
Из него получается **вертикальный ролик 9:16 с субтитрами**, готовый для TikTok, Reels и Shorts.

Работает круглосуточно и **без участия Claude**. Нейросеть вызывается только для заголовка
к готовому клипу (это необязательно): один короткий запрос, доли цента.

```
Twitch API ──> топ русских стримов GTA 6 (≥5000 зрителей)
                 │
   ┌─────────────┴──────────────┐
   ▼                            ▼
streamlink → ffmpeg         чат (IRC, анонимно)
буфер: последние 5 минут    темп сообщений + реакции (KEKW, ахах, WTF, +)
   │                            │
   │        «взрыв чата» ◄──────┘  темп ×3 от обычного у этого стримера
   ▼
вырезать [за 25 с до всплеска … 6 с после]
   ▼
whisper (расшифровка) → субтитры с подсветкой слов → 1080×1920 → громкость под соцсети
   ▼
data/clips/2026-11-19/153012_streamer/
    clip.mp4       ← готовый ролик
    caption.txt    ← заголовок, описание, хэштеги для публикации
    meta.json      ← расшифровка, сила всплеска, ссылка на источник
```

## Где запускать

Нужен компьютер или сервер, который работает 24/7. Облачная сессия Claude не подходит:
её контейнер временный.

| Что | Минимум | Комфортно |
|---|---|---|
| CPU | 4 ядра (2–3 стрима) | 8 ядер или видеокарта NVIDIA (6+ стримов) |
| RAM | 4 ГБ | 8 ГБ |
| Диск | 20 ГБ | 50 ГБ |
| Интернет | ~5 Мбит/с на каждый стрим 720p | |

Подойдёт обычный VPS (Hetzner, Timeweb, Selectel и т. п.) или ваш ПК с Linux/macOS/WSL.
Запись почти не грузит процессор (видео копируется без перекодирования). Нагрузка есть только
в момент монтажа клипа: примерно 1–2 минуты на клип на 4 ядрах.

## Установка

### 1. Ключи Twitch (бесплатно, 2 минуты)
1. Зайдите на https://dev.twitch.tv/console и войдите своим аккаунтом Twitch.
2. **Register Your Application** → Name: любое, OAuth Redirect URL: `http://localhost`, Category: `Other`.
3. Скопируйте **Client ID**, нажмите **New Secret** и скопируйте **Client Secret**.

### 2. Настройка
```bash
cd stream-clipper
cp .env.example .env                 # впишите TWITCH_CLIENT_ID и TWITCH_CLIENT_SECRET
cp config.example.yaml config.yaml   # настройки: стримеры, пороги, вид ролика
```
`ANTHROPIC_API_KEY` в `.env` необязателен. Без него у клипов будут шаблонные заголовки.

### 3а. Запуск через Docker (рекомендую для сервера)
```bash
docker compose run --rm clipper check   # проверка: ключи, ffmpeg, Twitch API
docker compose run --rm clipper top     # кто из русских стримеров сейчас в GTA 6
docker compose up -d                    # запуск 24/7 (переживает перезагрузку)
docker compose logs -f                  # смотреть, что происходит
```

### 3б. Без Docker
Нужны Python 3.10+ и ffmpeg (`sudo apt install ffmpeg` / `brew install ffmpeg`).
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m clipper check
python -m clipper top
python -m clipper run
```

## Команды

| Команда | Что делает |
|---|---|
| `run` | Основной режим 24/7 |
| `top` | Список русских стримов GTA 6 прямо сейчас, с числом зрителей. По нему удобно составить свой список |
| `chat-test <логин>` | Только слушает чат стримера и печатает темп и всплески. Нужна для настройки порогов, ничего не пишет |
| `twitch-clips` | Берёт самые просматриваемые клипы, которые зрители Twitch нарезали сами за последние 6 часов, и делает из них вертикальные ролики. Дешёвый второй источник; можно запускать по расписанию (cron) |
| `render <файл> --start 10 --duration 30` | Смонтировать ролик из своего видео. Проверка внешнего вида |
| `check` | Проверить установку и ключи |

## Кого пишем

По умолчанию берутся **русскоязычные** (`languages: ["ru"]`) стримы GTA 6
с **≥5000 зрителей**, до 6 самых популярных одновременно.

- Свой список стримеров — в `twitch.channels`. Они пишутся всегда, когда в эфире.
- Только свой список, без автопоиска: `only_listed: true`.
- Исключить кого-то: `blacklist`.
- Больше стримов одновременно: `top_n` (смотрите на нагрузку).

## Настройка «взрыва» чата

Момент считается интересным, когда **одновременно**:
- темп чата за последние 12 секунд в **3 раза** выше обычного для этого стримера.
  Обычный темп — медиана за 10 минут, поэтому у стримера с 50 сообщениями в секунду
  «взрыв» — это 150/с, а у стримера с 5/с — это 15/с;
- в окне **≥25 сообщений**;
- **≥15%** сообщений — реакции: `KEKW`, `LUL`, `ахах`, `WTF`, `+`, `клип`, КАПС и т. п.
  Список в `detector.reactions`. Без этого условия срабатывали бы розыгрыши и рейды.

Как подобрать пороги:
```bash
python -m clipper chat-test buster
```
Посмотрите 10–20 минут. Если 🔥 появляется слишком часто, поднимите `trigger_ratio` до 4.
Если моменты пропускаются, опустите до 2.5. Все найденные моменты также пишутся
в `data/clips/moments.jsonl`.

## Вид ролика

- `layout: split` (по умолчанию) — **стример крупным планом сверху, игра снизу, субтитры между ними.**
  Лицо стримера программа находит сама: берёт 8 кадров клипа и ищет лицо, которое стоит
  на месте. Лица персонажей в игре двигаются и отсеиваются. Найденное положение
  запоминается в `data/clips/facecams_auto.json`. Если в клипе лица не видно,
  используется прошлое положение, а если его нет — `blur`.
  - `face_zoom` — крупность: меньше число — крупнее лицо.
  - `split_top_ratio` — какую часть высоты отдать стримеру (0.42 = 42%).
  - Если у какого-то стримера автопоиск ошибается, задайте область вручную:
    `facecams: { evelone2004: [0.0, 0.55, 0.2, 0.3] }` (x, y, ширина, высота в долях кадра).
- `layout: blur` — весь кадр стрима по центру на размытом фоне.
- `layout: crop` — просто центр кадра.
- Субтитры крупные, с жёлтой подсветкой текущего слова. Шрифт и размер — в `render`.
  В `meta.json` клипа поле `subtitle_words` показывает, сколько слов распознано.
- `watermark: "@ваш_ник"` — подпись сверху.

## Сколько это стоит в токенах

- Слежение за чатом, запись, нарезка, субтитры: **0 токенов**, всё работает локально.
- Заголовок к клипу: один запрос к Claude примерно на 1–2 тыс. токенов.
  Модель задаётся в `titles.model`. Чтобы было ещё дешевле, поставьте `claude-haiku-5-5`.
- Claude Code нужен только чтобы что-то поменять в программе.

## Публикация и Telegram

Каждый готовый клип может приходить вам в Telegram: видео, а под ним заголовок,
описание и хэштеги, готовые к копированию. Под клипом кнопки **✅ Опубликовал**
и **🗑 Удалить** (удаляет клип и с компьютера). Новые клипы — новые сообщения,
так что вы не запутаетесь, что уже смотрели.

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин бота
   (логин должен заканчиваться на `bot`). BotFather пришлёт **токен**.
2. Впишите его в `.env`: `TELEGRAM_BOT_TOKEN=...` и перезапустите программу.
3. Найдите своего бота в Telegram и напишите ему **/start**. Бот запомнит вас
   и пришлёт клипы, которые накопились до этого. Чужим людям он ничего не шлёт.
4. Команда **/status** в боте — сколько стримов пишется и сколько клипов готово.

Клипы больше 49 МБ (лимит Telegram) для отправки уменьшаются до 720p; оригинал
в `data/clips/` остаётся в полном качестве.

## Права и риски — прочитайте

- Видео принадлежит стримеру. Перезалив без разрешения ведёт к жалобам, удалению роликов
  и блокировке аккаунта, особенно при монетизации.
  **Лучше договориться со стримерами** или работать через их официальные программы
  для клиперов (многие платят клиперам за просмотры).
- Музыка на стриме может дать отдельный страйк от правообладателя.
- Политика Rockstar разрешает некоммерческие видео с геймплеем, но это не отменяет права стримера.

## Ограничения

- Пока только Twitch. Kick и YouTube можно добавить: запись через streamlink работает
  с ними так же, нужен только модуль чтения их чата.
- Если игра на Twitch будет называться не «Grand Theft Auto VI», команда `top` выдаст ошибку.
  Тогда поправьте `game_name` или впишите `game_id`.
- Первый запуск качает модель whisper (`small` — около 500 МБ).
